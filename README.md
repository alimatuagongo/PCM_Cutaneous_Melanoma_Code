# PCM_Cutaneous_Melanoma_Code

This repository contains R code for analyzing cutaneous melanoma survival data using Promotion Time Cure Models (PTCMs) with machine learning methods for incidence modeling and Cox proportional hazards models for latency modeling.

## Methods Included

- Logistic Regression
- Spline-based Modeling
- Decision Tree
- Support Vector Machine (SVM)
- XGBoost
- Neural Networks
- Random Forest

## Features

- EM algorithm estimation
- Weighted Breslow baseline survival estimation
- Bootstrap inference
- ROC/AUC evaluation
- Cure probability estimation
- Survival function estimation

## Dataset

Cutaneous melanoma dataset used in cure model survival analysis.
